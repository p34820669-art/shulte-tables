# Таблицы Шульте

A casual cognitive game for kids 6 to 9, based on the webshow Нейроны. Tap the numbers (or letters) in order as fast as you can. Built with Phaser 4 and Vite, portrait layout for phones and desktop browsers.

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

## What is inside

- 30 levels in 5 worlds: numbers forward and backward, alphabet, even and odd, two colors, big tables.
- Daily table with a streak.
- Parent view (behind a simple gate) with progress charts. All data stays in the browser.
- `npm run assets` rebuilds the optimized images and sounds from the source art (local source folders only).
